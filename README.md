<h1>Burp Suite: The Basics </h1>


<h2>Description</h2>
This lab is an introduction to the basics of Burp Suite. Burp Suite is a framework used for web application penetration testing. I will use Burp Suite to capture and manipulate all of the HTTP/HTTPS traffic between a browser and web server. Burp Suite is an invaluable tool for manual web application testing. I will be using the Burp Suite Community edition throughout this lab.
<br />


<h2>Tools Used</h2>

- <b>Burp Suite</b>
- <b>Burp Proxy</b>
